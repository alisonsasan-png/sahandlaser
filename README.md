# Sahand Laser

Next.js foundation for the multilingual Sahand Laser industrial website.

## Current phase

- Four-language architecture planned: Persian, English, Arabic, Turkish
- Light-first corporate industrial visual system with dark mode foundation
- Configurable product categories and product detail routes planned
- Product media will be imported from `G:\سایت\SahandLaser-site-workspace\05-clean-catalog`
- Server-side country/language detection will be added with deployment-specific middleware

## Run

Install Node.js LTS, then run:

```bash
npm install
npm run dev
```
