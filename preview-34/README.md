# Preview 34

این پیش‌نمایش مستقل از Preview 33 است و از کامپوننت `components/ui/sneaker-product-hero.tsx` ساخته شده است.

## نسخه آنلاین

https://alisonsasan-png.github.io/sahandlaser/preview-34/

## ساختار React/shadcn برای توسعه

این ریپازیتوری فعلی GitHub Pages استاتیک است و پروژه React/shadcn فعال ندارد. برای استفاده از نسخه TSX:

```bash
npx create-next-app@latest sahand-preview-34 --typescript --tailwind --eslint --app
cd sahand-preview-34
npx shadcn@latest init
npm install gsap
mkdir -p components/ui
# فایل components/ui/sneaker-product-hero.tsx را از این ریپازیتوری کپی کنید
```

مسیر `components/ui` مسیر استاندارد shadcn برای کامپوننت‌های قابل استفاده مجدد است. فایل `preview-34/index.html` نسخه مستقل و قابل انتشار GitHub Pages است و برای اجرا به build React نیاز ندارد.
