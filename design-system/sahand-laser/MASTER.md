# Sahand Laser Design System

- Direction: official industrial, light-first with dark industrial mode.
- Pattern: Trust & Authority + Conversion.
- Palette: white `#ffffff`, ink `#102033`, steel `#506174`, accent blue `#0369a1`, primary green `#15803d`.
- Typography: Persian UI font with strong readable weights; technical labels use a monospace fallback.
- Motion: 150–200ms transitions; respect `prefers-reduced-motion`.
- UX: keyboard-visible focus, minimum 44px touch targets, accessible labels, no hover-only actions.
- Layout: mobile-first, responsive at 375px / 768px / 1024px / 1440px.
