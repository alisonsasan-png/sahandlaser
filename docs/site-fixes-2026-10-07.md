# گزارش اصلاحات سایت، ۷ اکتبر ۲۰۲۶

فقط مخزن سایت جدید و پیش‌نمایش GitHub Pages در محدوده کار است. سایت قدیمی، هاست و دامنه تغییر نمی‌کنند. کارها ترتیبی اجرا می‌شوند؛ بین کارها پنج دقیقه توقف و سقف هر کار یک ساعت است.

## ۱. نمایش موبایل و سه‌بعدی — partial

- شروع: ۰۷:۵۶ تهران. پایان بررسی کد: ۰۷:۵۸ تهران.
- کنترل‌های مدل زیر صحنه هستند؛ هنگام تغییر محصول iframe و observerها پاک‌سازی می‌شوند. وضعیت دکمه‌ها با نمایشگر همگام می‌ماند. لمس و تغییر اندازه صفحه در نمایشگر لحاظ شده‌اند.
- بررسی نحوی runtime/app.js و git diff --check موفق بود؛ bundle ساخته شد.
- Playwright اجرا نشد: Chromium نصب نیست و دانلود مرورگر فایل نامعتبر برگرداند. آزمون تصویری موفق اعلام نمی‌شود.
- تغییرات فقط در شاخه کاری نگه‌داری می‌شوند؛ انتشار روی main نیازمند بررسی وضعیت فعلی و تأیید تست‌ها است.
