# بازبینی پیش‌نمایش‌های ۴ تا ۸

تاریخ: ۸ اکتبر ۲۰۲۶

- هر پنج نشانی GitHub Pages با وضعیت HTTP 200 در دسترس است.
- نسخه‌های ۴ و ۵ ساختار دسته‌بندی را مقایسه می‌کنند؛ نسخهٔ ۴ به درخواست اولیه نزدیک‌تر است و نسخهٔ ۵ مارکینگ را در کنار سه فرایند دیگر حفظ می‌کند.
- نسخه‌های ۶ تا ۸ با Chrome در عرض ۳۹۰ پیکسل اجرا شدند و خطای JavaScript نداشتند.
- انیمیشن‌ها با CSS و JavaScript کوچک مشترک اجرا می‌شوند؛ ویدئو، کتابخانهٔ انیمیشن و فونت خارجی تازه‌ای اضافه نشده است.
- `prefers-reduced-motion` پیاده‌سازی شده تا حرکت برای کاربران حساس غیرفعال شود.
- تصاویر تجاری جدید هرکدام حدود ۱۴۹ تا ۱۶۵ کیلوبایت هستند.

بازبینی کامل صفحه‌کلید، دسکتاپ و ادغام با تمام صفحات پس از انتخاب ساختار و سبک نهایی انجام می‌شود تا کار تکراری روی پنج مسیر آزمایشی ایجاد نشود.
