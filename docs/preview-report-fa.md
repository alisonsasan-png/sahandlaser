# گزارش پیش‌نمایش‌های سهند لیزر

## مرکز لینک‌ها

صفحهٔ فهرست پیش‌نمایش‌ها: [مرکز پیش‌نمایش‌ها](../preview-lab/)

## وضعیت اجرا

- صفحات ۳۳، ۳۵ تا ۴۳، ۴۵ و ۴۶ منتشر شده‌اند.
- هر محصول مسیر اختصاصی دارد.
- ۲۹ نقشهٔ ابعادی آماده به محصولات متناظر متصل شده‌اند.
- محصول بدون نقشه با پیام شفاف نمایش داده می‌شود.
- عکس و ستون مشخصات محصول از هم جدا هستند.
- نسخه‌های موبایل و لینک‌های اصلی بررسی شده‌اند.

## ویژگی نسخه‌ها

| نسخه | ویژگی |
|---|---|
| ۳۳ | دسته‌بندی مانند ۲۹ و صفحهٔ محصول مانند ۳ |
| ۳۵ | دسته‌بندی ساختاری مانند ۳۰ و صفحهٔ محصول مانند ۳ |
| ۳۶ | نوار کناری و فهرست مقایسه |
| ۳۷ | کاتالوگ تحریریه‌ای |
| ۳۸ | انتخاب دوپنلی |
| ۳۹ | دفتر فنی و شبکهٔ نقشه |
| ۴۰ | منوی گرافیکی برش لیزر |
| ۴۱ | منوی گرافیکی جوش لیزر |
| ۴۲ | منوی گرافیکی حکاکی لیزر |
| ۴۳ | منوی گرافیکی تمیزکاری لیزر |
| ۴۵ | قالب اصلی سایت + دسترسی سریع مانند ۲۹ |
| ۴۶ | قالب اصلی سایت + دسترسی سریع مانند ۴۰ |

## نکتهٔ تصاویر

برای بعضی محصولات عکس اختصاصی وجود ندارد و تصویر عمومی خانواده نمایش داده می‌شود. این تصویر به‌عنوان عکس اختصاصی محصول معرفی نشده است.
