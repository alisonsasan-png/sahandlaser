# Catalog-first rebuild — 2026-10-11

## Boundaries

Original photos, main site and previews 2–11 remain unchanged. Existing iframe wrappers in previews 12–19 are not accepted as independent sites. New sites must embed their own catalog, routing, styles and interaction code, without base URLs, iframes or navigation to the main site. Product identities, articles and comparison rules must be identical across all variants.

## Order and acceptance gate

1. Inventory provided assets and documents, fix encoding in a derived catalog, reconcile duplicate identities, record evidence per field.
2. Review exact product photographs and create white studio versions. Preserve geometry and existing Sahand branding. Do not confuse a generated reconstruction with an original photo.
3. Verify internal assemblies using exact manufacturer manuals, supplied internal photos and assembly documents. A family BOM is not proof of component placement in a particular machine. Do not use unrelated supplier drawings as exact product diagrams.
4. Prepare technical diagrams and original Persian educational articles, with sources and variant applicability.
5. Only after catalog/media acceptance, implement independent previews 12–24.
6. Implement four proposed distinct interaction/design systems, previews 25–28. This is a finite first design set, not permission to produce unbounded variations.

No blanket “needs confirmation” badge is required in customer pages. Unknown configurable options must still be described as options, not installed parts. Schematic and reconstructed visuals retain accurate media-type captions and provenance. No invented specifications, performance guarantees or machine certification claims.

## Shared product navigation

Cutting → 3015 / 6020 / custom size / tube / robot. 3015 and 6020 each contain the exact nine requested names. Machines have comparison with the selected model plus two distinct random models in its own category; more products can be added without a three-item cap. Components and consumables do not have comparison.
