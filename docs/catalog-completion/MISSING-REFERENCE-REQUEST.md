# مراجع لازم برای نهایی‌سازی نقشه‌های ابعادی

این فهرست فقط برای مدل‌هایی است که نقشه‌ی Art-Line مرجع اولیه دارند اما ابعاد کلی کارخانه‌ای آن‌ها در منابع موجود ثبت نشده است.

## LR30

- عکس نمای کلی از روبه‌رو
- عکس نمای جانبی
- عکس نمای بالا
- اندازه‌ی کلی دستگاه: طول × عرض × ارتفاع
- اندازه‌ی میز کار و میدان مارکینگ
- محل چیلر یا واحد خنک‌کاری

## LG60

- عکس نمای کلی از روبه‌رو
- عکس نمای جانبی
- عکس نمای بالا
- اندازه‌ی کلی دستگاه: طول × عرض × ارتفاع
- اندازه‌ی میز کار و میدان مارکینگ
- محل چیلر یا واحد خنک‌کاری
